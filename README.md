# AI-Powered Health Risk Profiler

Full-stack project (backend + frontend) for the assignment. See backend/ and frontend/ folders.

## Quickstart
1. Backend: `cd backend && npm install && npm run dev`
2. Frontend: `cd frontend && npm install && npm start`

Backend listens on port 4000 by default. Frontend (Parcel) on 3000.

API endpoint: POST /api/parse (accepts multipart image + text OR JSON body with text)
